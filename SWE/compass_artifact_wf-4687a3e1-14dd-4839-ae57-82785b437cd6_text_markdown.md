# Reference Corpus: Operational Use of C and C++ in Embedded Contexts (GCC & LLVM/Clang Focus)

## TL;DR
- This is a breadth-first, tag-sorted corpus of ~65 verified resources covering the OPERATIONAL use of C/C++ on embedded targets—toolchains, optimization, debugging, binary/linker mechanics, and memory management—grafted onto the prior embedded-C and embedded-C++ design corpora; overlap is retained and tagged, not dropped.
- Absolutely-key primary references are verified and live: the Itanium C++ ABI (cpp-leaf runtime machinery), the GNU ld/GCC/GDB/Binutils manuals, the ARM ABI-AA suite (AAPCS, EHABI32, CPPABI, semihosting), DWARF v5, the TIS ELF spec, and canonical blog canons (Memfault Interrupt "Zero to main()", Ian Lance Taylor's 20-part Linkers series, MaskRay's "All about…" linker series).
- Each entry carries four sort keys (tier / theme / type / verification); a short "Unverified / to confirm" section quarantines leads that could not be fully confirmed, and a coverage note flags where recall likely thins (vendor app-notes with specific document numbers, and some individual blog-post titles).

## Key Findings
- The C++-specific runtime machinery (vtables, name mangling, exception unwinding/LSDA/personality routines, `__cxa_*` runtime, static-init guard variables) is authoritatively documented by the **Itanium C++ ABI** (living doc, itanium-cxx-abi.github.io) supplemented by the **Exception Handling in LLVM** doc and **ARM EHABI32** — these are the load-bearing cpp-leaf references.
- Trunk toolchain/linker/debugger material is dominated by continuously-maintained GNU/LLVM manuals; the observed current versions are recorded (GCC 17-pre series, GDB 10th edition / v18-dev, Binutils ld 2.4x, OpenOCD 0.12.0+dev, DWARF v5 2017 with a v6 working draft in progress).
- Memory-management operational canon rests on a small set of primary works (Doug Lea's dlmalloc essay, the TLSF ECRTS 2004 paper, FreeRTOS heap docs) plus footprint tooling (Bloaty, puncover) and GCC's `-fstack-usage`.

### THEME 4 — BINARY / LINKER (ELF, linker scripts, ABIs, startup)

**Official documentation & standards**
- *The GNU Linker (ld)* — Steve Chamberlain et al., GNU Project/FSF, part of GNU Binutils (sourceware.org/binutils/docs/ld). Observed Binutils versions 2.37/2.38 through 2.46 docs. Linker-script chapter: SECTIONS, MEMORY, KEEP, overlays, VMA/LMA, PHDRS, NOCROSSREFS, --gc-sections. [tier: trunk | theme: binary-linker | type: official-doc | verified-exists] KEY.
- *LLD — The LLVM Linker* — LLVM Project (lld.llvm.org). Living doc (observed 23.0.0git). Drop-in GNU-compatible ELF linker; accepts GNU linker scripts; LTO support. [tier: trunk | theme: binary-linker | type: official-doc | verified-exists].
- *Itanium C++ ABI* — Itanium C++ ABI group (itanium-cxx-abi.github.io/cxx-abi/abi.html; mangling revision 5 Sep 2000; repo github.com/itanium-cxx-abi/cxx-abi). Vtable layout, name mangling, `__cxa_*` runtime, guard variables for static init, VTT/construction vtables, RTTI. Used by GCC & Clang. [tier: cpp-leaf | theme: binary-linker | type: official-doc | verified-exists] ABSOLUTELY KEY; cpp-leaf because it defines C++ object-model runtime with no C equivalent.
- *Procedure Call Standard for the Arm Architecture (AAPCS)* — Arm Ltd, ABI-AA (aapcs32 2020Q2; aapcs64). Register/stack calling conventions, alignment, parameter passing. [tier: trunk | theme: binary-linker | type: official-doc | verified-exists] KEY.
- *Exception Handling ABI for the Arm Architecture (EHABI32)* — Arm Ltd, ABI-AA (ehabi32, 2018Q4; github.com/ARM-software/abi-aa/blob/main/ehabi32/ehabi32.rst). Table-based unwinding, EH encoding in ELF, C++ EH aspects (Itanium-model based). [tier: cpp-leaf | theme: binary-linker | type: official-doc | verified-exists] KEY cpp-leaf (unwinding machinery).
- *Tool Interface Standard (TIS) Executable and Linking Format (ELF) Specification, Version 1.2* — TIS Committee, May 1995 (refspecs.linuxfoundation.org/elf/elf.pdf). Generic ELF object/executable format. Plus the maintained *System V Application Binary Interface* (generic gABI). [tier: trunk | theme: binary-linker | type: official-doc | verified-exists] KEY.
- *DWARF Debugging Information Format, Version 5* — DWARF Debugging Information Format Committee, February 2017 (dwarfstd.org/dwarf5std.html). DIEs, .debug_* sections, line-number program, call-frame info; v6 working draft (2023) in progress. [tier: trunk | theme: binary-linker | type: official-doc | verified-exists] (debugging-adjacent; primary theme binary-linker for section/format mechanics).
