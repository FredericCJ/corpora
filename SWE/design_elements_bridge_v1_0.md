# SWE Corpus — Design ↔ Architecture Bridge v1.0 (`element-bridge`)

**Scope.** The typed, provenance-tagged relation layer between the two element realms — `design_elements_catalog_v1_0.md` (709 elements) and `architecture_elements_catalog_v1_0.md` — plus within-realm element relations and idiom→element realization edges. Compiled 2026-07-11.

**Bridging rule (mission-critical).** Every design-realm element carries ≥1 typed relation to ≥1 *specific* architecture-realm element, or appears on the explicit unbridged list with a rationale. Audited mechanically below.

## Edge-kind vocabulary

| kind | direction | semantics |
|---|---|---|
| `realizes` | design → architecture | the design element is an implementation-level realization of the architecture element (Observer → publish-subscribe style; retry-with-backoff → retry tactic) |
| `enables` | design → architecture | the design element is a load-bearing mechanism the architecture element depends on (event loop → event-driven architecture) |
| `constrains` | architecture → design | the architecture element constrains the choice/shape of the design element (ARINC 653 partitioning → static allocation) |
| `implements` | design → design | a language idiom/mechanism realizing a more abstract design element (signals-and-slots → observer) |
| `specializes` | within one realm | the source is a more specific form of the target |
| `composes-with` | within one realm | the pair is characteristically composed (symmetric; stored once, direction not meaningful) |
| `alternative-to` | within one realm | competing solutions to the same forces (symmetric; stored once) |

**Provenance.** `sourced` = the relation is stated in a citable source (cited per edge); `editorial` = reasoned judgment, marked as such, never presented as fact.

**Census.** **1132 edges** — cross-realm 878 (realizes 544 · enables 324 · constrains 10), implements 39, within-realm 215 (specializes 61 · composes-with 89 · alternative-to 65). Provenance: **328 sourced : 804 editorial** (29% sourced). Bridging rule: **703/709** design elements bridged; **6 unbridged** (list below).

**Edge grammar** (machine-parseable; Phase 4 ingests): ``- `from` kind `to` — provenance[: cite] — note``
